# Nhật ký dự án

Ghi lại những gì đã làm, đã học và đã quyết định, **viết trong tuần** chứ không viết bù. Đây là nguồn để viết blog, CV và luyện phỏng vấn ở tuần 12.

| Loại file | Tên | Khi nào viết |
|---|---|---|
| Nhật ký tuần | `YYYY-Www.md` (tuần ISO), ví dụ [`2026-W41.md`](2026-W41.md) | Chủ nhật cuối mỗi tuần |
| Ghi chú đọc | `notes-<chủ-đề>.md`, tối đa 1 trang mỗi tài liệu | Ngay sau khi đọc |
| Spike | `spike-<chủ-đề>.md`, kèm log hoặc ảnh chụp | Khi thử nghiệm trước lúc code |

## Mẫu nhật ký tuần

```markdown
# Nhật ký 2026-Wnn (tuần N: <chủ đề>)

## Đã làm
- Wxx-yy: ... (PR #, issue #)

## Thời gian
Dự kiến X giờ, thực tế Y giờ. Lệch vì ...

## Học được
## Khó khăn và cách gỡ
## Quyết định (link ADR)
## AI đã giúp gì (link ai-usage)
## Tuần sau
```
